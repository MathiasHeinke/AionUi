# Checkliste — KDP Kindle eBook veröffentlichen

Start: vom Taschenbuch aus **„+ Kindle eBook erstellen"** (verknüpft die Formate).

## Tab 1 · Details
- [ ] Metadaten und Rechte erneut geprüft; **Mensch attestiert Rechte**
- [ ] **Kindle-Kategorien neu gewählt** (anderer Baum als Print)

## Tab 2 · Inhalt
- [ ] Mensch hat `book.epub` nach Agent-Preflight hochgeladen; Konvertierung ok
- [ ] **DRM durch Menschen entschieden** — änderbar, aber frühere DRM-freie Downloads bleiben
- [ ] Verwendete KI-Verfahren inventarisiert; **Mensch bestätigt KI-Offenlegung**
- [ ] Mensch hat das freigegebene Cover-JPEG hochgeladen
- [ ] Cover entspricht aktueller Kindle-Empfehlung (derzeit ca. 1,6:1) und KI-Herkunft ist inventarisiert
- [ ] Barrierefreiheit gesetzt
- [ ] Agent-Prüfbericht aus menschlich gestarteter Preview: schmales Gerät +
  große Schrift → Code/Tabellen brechen um; Mensch genehmigt

## Tab 3 · Preise
- [ ] **Mensch entscheidet KDP Select** (90 Tage Digitalexklusivität)
- [ ] 35-%-/70-%-Bedingungen und Preisgrenzen live geprüft
- [ ] Marketplace-Preis inklusive USt. sowie geschätzte Tantieme geprüft
- [ ] Liefergebühr geprüft (kleines JPEG-Cover hilft)
- [ ] Jeder externe Link führt auf eine live geprüfte, KDP-konforme Seite ohne Kundendaten-Formular

## Gate
- [ ] Mensch bestätigt Rechte, KI-Offenlegung, DRM, KDP Select, Preis und Termin
- [ ] **Mensch klickt „Veröffentlichen"/„Vorbestellung absenden"**; Agent protokolliert nur Receipt
